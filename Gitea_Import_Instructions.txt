TROUBLESHOOTING
--------------
- If push fails with "repository not found":
  1. Ensure repository is created on Gitea.com first
  2. Verify you have proper SSH access
  3. Test connection: ssh -T git@gitea.com

- If files are too large:
  1. Use git lfs for large files
  2. Push in smaller batches:
     ```bash
     git add . --batch=500
     git commit -m "Batch import"
     git push
     ```
